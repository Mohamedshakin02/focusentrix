# Focusentrix

Focusentrix is a smart web-based productivity platform developed by WD Team 19 as a Final Year Project for the Creative Incubator module. The platform is designed to help users improve concentration and reduce distractions during study or work sessions through real-time focus monitoring and productivity tools.

The core innovation of Focusentrix is its real-time focus detection system powered by the MediaPipe machine learning library. Using the user's webcam directly within the browser, the platform continuously monitors attention and detects distraction in real time. When a user looks away from the screen or remains distracted for an extended period, visual and audio alerts are triggered to help bring their focus back to the session.

Unlike traditional productivity applications that only track study time, Focusentrix actively monitors user engagement during a session. This enables users to better understand their focus habits and improve productivity through real-time feedback.

In addition to focus detection, the platform includes several productivity features such as task management, a customizable Pomodoro timer, background music, streak tracking, and focus analytics. Users can manage tasks, track daily productivity habits, monitor focus performance, and build consistency over time.

## Features

* Real-time focus detection using MediaPipe
* Distraction alerts with audio and visual notifications
* Focus score and productivity analytics
* Task management with to-do lists
* Customizable Pomodoro timer
* Background music for study and work sessions
* Daily streak tracking
* Google Authentication
* Free and Pro subscription plans
* Protected routes and user-based access control
* Fully responsive design for desktop, tablet, and mobile devices
